# Project Command Palette

Build a VS Code-style command palette for the currently selected project. `Cmd+P` on
macOS and `Ctrl+P` on Linux opens one shadcn/cmdk dialog spanning every visible worktree
in that project. Results combine workspace metadata, GitHub pull requests, live agents,
terminal sessions, filenames, and matching code lines without searching other projects.

### Palette composition

Add shadcn's command primitive with `bunx shadcn@latest add command`; this introduces
`cmdk` and `apps/pragma/src/components/ui/command.tsx`. Build feature UI under
`apps/pragma/src/components/command-palette/`, not inside the generated primitive.

Add `fuzzysort` to `apps/pragma/package.json`. Set `shouldFilter={false}` on cmdk:
Pragma must rank already-loaded local rows and asynchronous host rows consistently,
apply worktree-recency tie breaks, and omit categories after thresholding.

```text
components/command-palette/
├── CommandPalette.tsx          dialog, input, groups, keyboard behavior
├── use-command-palette.ts      query generation and source orchestration
├── palette-results.ts          source joins, category caps, section omission
├── palette-ranking.ts          fuzzysort adapters and accepted-match thresholds
└── palette-navigation.ts       target-specific actions
```

Mount `CommandPalette` inside `RightSidebarProvider` in
`components/workspace/WorkspaceShell.tsx`. Wrap its open lifetime with
`useSuppressNativeOverlayWhile(open)` so native browser views cannot cover the dialog.

Local palette state is intentionally ephemeral:

```ts
type PaletteState = {
  open: boolean;
  query: string;
  scopedWorktreeId: string | null;
  generation: number;
};
```

Closing resets query and scope. Worktree selection sets scope without navigating and
clears query. Backspace on an empty scoped query returns to all visible worktrees.
Escape closes the dialog. Project change closes and resets the palette.

### One host-owned search operation

Do not recursively call `listDirEntries` from React and do not depend on a user-installed
`rg`. Both approaches fail on remote worktrees or create per-keystroke RPC storms.

Add `crates/pragma-core/src/search.rs` and extend `FsRequest` in
`crates/pragma-core/src/fs.rs` with bounded search and cancellation operations. Add Rust
dependencies:

- `ignore` for recursive traversal matching gitignore/global-ignore semantics
- `nucleo-matcher` for fast fuzzy filename candidate scoring
- `grep-searcher` plus `grep-regex` for bounded in-process literal line search

`SearchService` belongs to `Core`, shared across server connections. It owns active
search cancellation tokens and concurrency permits. Do not add a persistent content
index in v1; measure traversal latency first. A later filename-only cache can sit behind
the same contract without changing UI APIs.

```rust
enum FsRequest {
    // existing operations
    PaletteSearch {
        search_id: String,
        roots: Vec<PaletteSearchRoot>,
        query: String,
        include_files: bool,
        include_code: bool,
        file_limit: u32,
        code_limit: u32,
        deadline_ms: u64,
    },
    CancelPaletteSearch { search_id: String },
}
```

Tauri receives only `projectId`, optional `worktreeId`, query, and search id. It validates
membership, removes hidden worktrees, resolves trusted absolute roots from SQLite, and
routes one RPC through the project's owning `PragmaClient`. Absolute roots exist only on
the native-client-to-host boundary; responses contain worktree-relative paths only.

Hard bounds:

- 256-byte query
- 64 worktree roots
- 100 filename candidates and 100 code candidates before frontend caps
- 512-byte code snippet
- 2 MiB maximum searchable file
- no symlink traversal outside canonical worktree roots
- skip `.git`, ignored, binary, and oversized files
- two concurrent palette searches per host
- deadline checked during traversal; cancellation checked between files and line batches

Bump `daemon.protocolVersion` so an old remote server cannot appear compatible while
lacking the new filesystem operation.

### Worktree MRU

Creation time is not recency. Add SQLite migration v11 with a client-local table:

```sql
CREATE TABLE worktree_mru (
  worktree_id TEXT PRIMARY KEY REFERENCES worktrees(id) ON DELETE CASCADE,
  project_id TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
  last_used_at INTEGER NOT NULL
);
CREATE INDEX idx_worktree_mru_project
  ON worktree_mru(project_id, last_used_at DESC);
```

Touch MRU from one selection effect in `WorkspaceProvider`, not individual click paths.
This captures sidebar clicks, agent notifications, deep links, PR actions, and palette
navigation. Expose a project MRU query through `lib/tauri.ts`; keep MRU out of shared
`Worktree`, `WorkspaceSnapshot`, and host mirror types because it is desktop-user UI state.

### Terminal title and last command

Titles already persist through OSC 0/2. Last command does not exist and must not be
guessed from PTY input or scrollback. Add shell integration for zsh, bash, and fish that
emits a private, base64-encoded OSC marker from preexec. Preserve user hooks and fall
back to normal shell startup when integration is unsupported.

Extend the server OSC parser in `crates/pragma-server/src/session.rs` to strip and decode
the marker, cap it, reject malformed/control-character payloads, and store the latest
command in session runtime metadata. Expose a batched terminal-metadata server RPC keyed
by session/tab id. Treat values as untrusted display text.

## Ranking and Section Rules

Top-level categories keep fixed order. Agent states are nested subcategories, not peer
categories:

```text
Go to worktree
Worktrees
Pull requests
Agents
  Needs attention
  In progress
  Finished
Files
Terminal tabs
Code
```

For a non-empty query:

1. Fuzzy metadata and filename candidates with category-specific searchable fields.
2. Reject candidates below the configured normalized acceptance threshold.
3. Omit any section whose accepted row list is empty.
4. Sort accepted rows by similarity descending, then worktree `last_used_at` descending, then stable label/id.
5. Never let recency promote a weaker match over a stronger match.

Use `fuzzysort` for frontend-owned rows and `nucleo-matcher` for host filename discovery.
Do not compare raw scores across libraries. Normalize each matcher to an internal
`0..1` quality and verify equivalent match classes with shared fixtures: exact, token
exact, prefix, contiguous substring, compact subsequence, sparse subsequence, rejected.
Start with a conservative `0.45` acceptance threshold and tune using fixture-based tests,
not ad hoc production exceptions. Code results are accepted only on actual literal line
matches; no code match means no Code section.

Empty query uses bounded defaults without disk/content scans:

- Worktrees: current first, then MRU, cap 8.
- PRs: cached open PRs, cap 6.
- Agents: one category containing Needs attention, In progress, and Finished subcategories; live entries use status priority and MRU order, cap 5 per subcategory. Omit an empty subcategory, and omit Agents when all three are empty.
- Files: currently open editor/diff file tabs, deduplicated by worktree and path, cap 8.
- Terminal tabs: current first, then MRU worktree and tab creation order, cap 8.
- Code: omitted until at least two non-whitespace query characters.
- Any empty default category is omitted.

## Async Behavior

The dialog and local defaults render in the first frame. On each non-empty query:

- Debounce host search by 100 ms.
- Increment a generation id and cancel the previous host request.
- Use `useDeferredValue` for result ranking/rendering while keeping input controlled and urgent.
- Use `startTransition` when committing result arrays.
- Require exact project, scope, query, and generation match before accepting a response.
- Abort PR refresh independently from host search.
- Keep loading and errors category-local; never toast per keystroke.

Remote disconnect, timeout, or one failed worktree leaves local categories usable. Show a
small non-selectable Files/Code error row only when that source was requested; do not
mistake an error for a no-match section. Deleting or hiding a scoped worktree clears scope
and reruns the current-project query.

## Acceptance Criteria

- <Badge>Scope</Badge> Results come only from non-hidden worktrees under selected project.
- <Badge>Speed</Badge> Shortcut opens local defaults immediately; typing never waits on Rust, SSH,
  or GitHub.
- <Badge>Quality</Badge> Weak fuzzy results are rejected and empty result sections are absent.
- <Badge>Order</Badge> Similarity sorts first; persisted worktree MRU breaks ties.
- <Badge>Navigation</Badge> Every row reaches correct worktree and destination without selection
  races.
- <Badge>Remote</Badge> Filename/code search runs on owning host with relative-path responses.
- <Badge>Privacy</Badge> Last command is runtime-only, bounded, untrusted, and never
  persisted/logged.
- <Badge>Resilience</Badge> Stale responses, partial errors, and disconnected hosts cannot overwrite
  current results or freeze palette.
