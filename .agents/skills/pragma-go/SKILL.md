# Pragma Go (Expo) development

`apps/pragma-go` is an Expo SDK 57 app that mirrors the desktop sidebar's
worktree navigation and turns agent approvals/questions into a swipeable inbox.
**Front-end only** today — data comes from `lib/data/fixtures.ts` behind
`lib/data/data-context.tsx`. See `apps/pragma-go/AGENTS.md` for the full map.

## Non-negotiables

- **Dev build, not Expo Go.** Native modules (liquid glass, native tabs,
  gesture-handler + reanimated 4) require `expo run:ios` / `expo run:android` or an
  EAS dev client. Expo Go will crash on these.
- **Domain types come from `@pragma/constants`** (type-only import). Do not redefine
  `Project` / `Worktree` / `AgentStatus` / `AgentAttentionKind`. Keep
  `lib/worktree-tree.ts` and `lib/agent-status.ts` in lockstep with the desktop's
  `apps/pragma/src/lib/worktree-tree.ts` + agent-status rollup.
- **Go through the wrappers**, never the native lib directly:
  - haptics → `lib/haptics.ts` (`hapticSelection/Impact/Success/Warning`)
  - liquid glass → `components/GlassSurface.tsx` (`isLiquidGlassAvailable` fallback)
  - icons → `components/IconSymbol.tsx` (SF Symbol on iOS, Lucide on web, unicode
    glyph on Android)
  - native menus → `components/ui/menu-view.tsx`
  - secrets → `lib/secret-store.ts`; gateway fetch → `lib/gateway-fetch.ts`

## Web build

The same tree builds for the browser; `pragma-gateway` serves the export under
`/web`. Two rules carry most of the weight:

- **A `.web.ts(x)` twin, never a `Platform.OS === "web"` branch** in a shared module.
  The twin is also what keeps native-only module graphs (`@expo/ui/swift-ui`,
  `react-native-webview`, `expo-secure-store`) out of the web bundle. Keep the two
  files' exported names identical — TypeScript checks callers against the native one.
- **Wide layouts swap the bar, not the navigator.** iPad gets the system sidebar from
  `NativeTabs sidebarAdaptable`; web and Android tablets render `AppSidebar` in place
  of the tab bar above `WIDE_LAYOUT_BREAKPOINT` (`lib/use-wide-layout.ts`). Swapping
  the whole navigator on resize would reset navigation state.

Check web work with `bun run --filter pragma-go export:web` — it catches an
unresolvable native import that a native build never sees.

## Routing (expo-router)

- File-based under `app/`. Route groups `(tabs)`, `(projects)` are hidden from URLs.
- Native bottom tabs: `expo-router/unstable-native-tabs`. Only `NativeTabs` and
  `NativeTabTrigger` are named exports; icons/labels/badges are compound:
  `NativeTabs.Trigger.Icon` (`sf` + `drawable` props), `.Label`, `.Badge`.
- Per-screen header/title/headerLeft: render `<Stack.Screen options={...} />` inside the
  screen (typed routes are on, so `router.push({ pathname, params })` is type-checked).
- Header-**right** uses module-level renderers so hook-owning buttons remain stable.
  Project root and chat use `NewWorktreeButton` "+" for the New Worktree sheet; worktree
  screens use `LaunchAgentButton` "+" for the Launch Agent sheet. The all-projects list
  has no header button; the stack's native back button handles escaping the drill-down.

## Styling (NativeWind v4 + React Native Reusables)

- Theme tokens are CSS variables in `global.css` (light + `.dark:root`), surfaced through
  `tailwind.config.js`. Use semantic classes (`bg-card`, `text-muted-foreground`,
  `bg-success`), not raw colors.
- `babel.config.js` needs `jsxImportSource: "nativewind"` and the
  `react-native-worklets/plugin` **last**. `metro.config.js` wraps `withNativeWind` and
  watches the monorepo root — don't drop that when editing Metro config.
- Add primitives with `npx @react-native-reusables/cli@latest add <name>`; they land in
  `components/ui/` and depend on `@rn-primitives/*`, `class-variance-authority`, `cn()`.

## Inbox card gesture

`components/InboxCard.tsx` uses `ReanimatedSwipeable`. Swiping **right** reveals the LEFT
action = approve/submit; swiping **left** = deny (`onSwipeableOpen(direction)` where
`direction === "left"` means the left action opened). Submitting a question requires a
selected radio option or non-empty "Other" text, else it warns and snaps back. Every
resolution fires haptics and dismisses the card.

## Home-screen widgets (`lib/widgets/`, iOS)

`expo-widgets` + `@expo/ui/swift-ui`. Widgets are declared in `app.json` under the plugin
and created with `createWidget(name, layout)`; the extension target is generated by
prebuild, so adding or renaming one needs `expo run:ios`, not just a Metro reload.

- A function carrying the `'widget'` directive is **stringified by Babel** and evaluated
  in the extension against a runtime whose only globals are the `@expo/ui/swift-ui`
  exports/modifiers. It can close over **nothing** — no module constant, no imported
  helper, no shared color token. Inline helpers and literals; pass data through props.
- A mapped list must be its container's **only** child. The extension keeps element-node
  children only and does not flatten arrays, so `{items.map(...)}` beside siblings is
  dropped silently — the list renders empty. Wrap it in its own `VStack`/`HStack`.
- Widgets cannot call the host. `lib/widgets/use-widget-sync.ts` pushes a snapshot from
  the running app (coalesced to one push per 15s; WidgetKit budgets reloads), so a widget
  shows state as of the app's last run.
- Derive in `lib/widgets/widget-data.ts` (pure, Vitest), render dumbly in `widgets.tsx`.
- Mirror the app's own structure. `PragmaProjects` nests each project's worktrees under it
  in `buildWorktreeTree` order, keeping only live ones (`running`/`attention`, or `done`
  and unviewed) plus the ancestors holding them; row counts are capped in `widget-data.ts`
  and trimmed again per widget family.
- Use SwiftUI named colors (`red`/`orange`/`green`/`gray`), not the app's tokens — there
  is no NativeWind theme in an extension, and named colors adapt to tinted rendering.
- Deep links come from the app (`expo-linking` `createURL`): `widgetURL` for the whole
  widget, `Link` for individual rows.
- Set `containerBackground(color, "widget")` on every system-family layout, keyed off
  `environment.colorScheme` — `expo-widgets` adds none, and the fallback backdrop stays
  dark in light mode. Skip it on `accessory*` families (the Lock Screen owns that).
- `supportedFamilies` is native: after editing it in `app.json`, `bun run prebuild` and
  reinstall the dev client. Layout edits alone need no rebuild.

## Gotchas

- **Bun linker must be hoisted.** Root `bunfig.toml` sets `[install] linker = "hoisted"`.
  Bun's default isolated linker hides Expo's Babel plugins from Node resolution and Metro
  fails with `Cannot find module 'babel-preset-expo'`. Don't remove it.
- Reanimated 4 requires `react-native-worklets` (separate package) + its babel plugin.
- SF Symbols only render on iOS; always pass an `IconSymbol` `fallback` glyph for Android/web.
- `@pragma/constants` exports source TS that imports a generated file — run
  `bun run generate` (or `bun run typecheck` from root, which generates first) before
  `tsc` in this app will resolve the types.
