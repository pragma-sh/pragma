---
title: Usage limits (deprecated)
description: defineUsageLimitProvider is deprecated — declare an account provider with defineAccounts instead.
---

<Callout title="Deprecated" type="warn">
  `defineUsageLimitProvider` and the `usageLimits` plugin field are deprecated. Use
  [`defineAccounts`](/docs/plugins/accounts), which adds sign-in, per-account usage, and account
  switching.
</Callout>

Plugins that still declare `usageLimits` keep working. Pragma adapts each provider into a
single-login [account provider](/docs/plugins/accounts):

- its `id` becomes the provider key (it will not merge with other plugins' rows),
- `title`, `iconPath`, `dashboardUrl`, `primaryLimitId`, `refreshIntervalMs` and `load` carry
  over unchanged,
- it has one account — the harness's own login — shown with a **legacy** badge, with no
  sign-in and no switching.

To migrate, move the provider's fields under `usageLimits` of an account provider:

```ts
// Before
usageLimits: [
  defineUsageLimitProvider({
    id: "my-agent",
    title: "My Agent",
    dashboardUrl: "https://my-agent.dev/usage",
    primaryLimitId: "messages",
    load: loadUsage,
  }),
],

// After
accounts: defineAccounts([
  {
    provider: "anthropic",
    agent: "my-agent",
    dashboardUrl: "https://my-agent.dev/usage",
    usageLimits: { primaryLimitId: "messages", load: loadUsage },
  },
]),
```
